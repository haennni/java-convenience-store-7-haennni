> 우아한테크코스 7기 4주차 미션, 편의점을 구현한 저장소입니다.

---

## 📝 프로젝트 개요
이 프로젝트는 구매자의 할인 혜택과 재고 상황을 고려하여 최종 결제 금액을 계산하고 안내하는 결제 시스템입니다.

## 🎮 기능 목록
1. **구매할 상품과 수량을 입력받기**
   - 상품명과 수량을 하이픈(-)으로, 개별 상품은 대괄호([])로 묶어 입력합니다. ex)[콜라-10],[사이다-3]
   - 쉼표(,)로 구분합니다.
   - 쉼표(,)가 없을 경우 예외가 발생합니다.
   - 수량이 문자열이거나 음수일경우 에외가 발생합니다.

2. **결제 가능 여부 확인**
   - 고객이 구매할 상품들의 수량을 받아 재고보다 작은지 확인합니다.
   - 고객이 상품을 구매하면 해당 상품의 재고에서 수량을 차감합니다.
   - 재고의 수량이 0개가 될 경우 -> 재고없음으로 표시합니다.
  
3. **프로모션 할인 여부**
   - 고객이 구매할 상품들의 이름을 받아 편의점 상품리스트에서 찾습니다.
   - 일치하는 상품의 프로모션을 확인합니다.
   - 구매 날짜(오늘 날짜)가 프로모션 기간 내에 포함된 경우 할인을 적용합니다.
   - 프로모션 재고를 우선적으로 차감합니다. -> 재고가 부족할 경우 일반 재고를 사용합니다.
   - 프로모션 적용이 가능한 상품에 대해 사용자가 수량보다 적게 가져온 경우 혜택을 알려줍니다.
   - 프로모션 재고가 부족하여 프로모션 혜택 없이 결제해야 하는 경우 일부 수량에 정가로 결제하게 됨을 알려줍니다.

4. **멤버십 할인 여부**
   - 사용자에게 멤버십 할인 여부를 묻습니다.
   - 할인 여부가 "Y"일 경우 프로모션 미적용 금액의 30%를 할인받습니다.
   - 프로모션 적용 후 남은 금액에 대해 멤버십 할인을 적용합니다.
   - 할인의 최대 한도는 8,000원 입니다.

5. **영수증 출력**
   - 구매 상품 내역(구매한 상품명 & 수량 & 가격), 증정 상품 내역(프로모션에 따라 무료로 제공된 증정 상품), 금액 정보(총 구매액, 행사 할인, 멤버십할인, 총 금액 )등을 영수증으로 보여줍니다.
  

6. **추가 구매 여부**
   - 사용자가 추가 구매를 원할 경우 구매할 상품과 수량을 다시 입력받습니다.
   - 추가 구매를 원하지않을 경우 편의점 프로그램이 종료됩니다.


## 🚀 예외 상황
- **공통 사항**
  - 예외 상황 시 에러 문구를 출력합니다.
  - 에러 문구는 "[ERROR]"로 시작해야 합니다. (ex. ERROR] 올바르지 않은 형식으로 입력했습니다. 다시 입력해 주세요.)

- **상품 구매 예외**
  - 구매할 상품이 존재하지 않는 경우 예외발생
  - 구매할 상품의 수량이 음수 혹은 문자열인경우 예외발생
  - "-"이 존재하지 않는 경우 예외발생
  - 구매 수량이 재고 수량을 초과한 경우 예외발생
